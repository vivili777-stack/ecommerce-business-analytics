# E-Commerce Business Analytics

End-to-end data analysis of 540K+ e-commerce transactions (UCI Online Retail Dataset) using SQL, Python (pandas), and Tableau.

## Analysis Dimensions

| Dimension | Key Finding |
|-----------|-------------|
| **Customer Segmentation** | Top 10% of customers contribute 60%+ of total revenue |
| **Product Analysis** | Broad-demand vs. bulk-driven products require different strategies |
| **Monthly Trends** | Revenue growth driven by order volume & active customers, not AOV |
| **Cohort Retention** | Sharp M0→M1 retention cliff, stabilizing at non-zero level |
| **RFM Segmentation** | 35% Champions contribute 74% of total revenue |
| **A/B Test Design** | Early activation intervention → +5.77pp D30 repurchase lift (z=4.59, p<0.0001) |

## Tech Stack

- **Data Preparation**: SQL (SQLite)
- **Analysis & Visualization**: Python (pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels)
- **Dashboards**: Tableau
- **Statistical Methods**: Pearson correlation, paired t-test, two-proportion z-test, power analysis

## Dataset

[UCI Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/online+retail) — 541,909 transaction records from a UK-based online retailer (Dec 2010 – Dec 2011).
